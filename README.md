# Github Profile

> A Search Engine for Github Profiles

A one page web application that allows users to search for Github profiles and view their repositories, followers, and following. The application is built using React and the Github API.

## Running Locally

You can run this project locally by following these steps:

```shell
npm i
npm run dev
```

The application will be available at `http://localhost:5173/`.
